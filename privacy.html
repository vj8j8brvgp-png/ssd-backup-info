プライバシーポリシー

SSD Backup は、所有者本人の Mac と Google Drive で利用する個人用バックアップアプリです。このページは、設定完了後に予定しているデータの取り扱いを説明します。現在、Google の認可とバックアップ設定は未完了です。

Google データへのアクセスと利用目的

Google OAuth の drive.file 権限を使用し、このアプリが作成したバックアップ用ファイルを対象に、一覧取得・読み取り・書き込み・削除を行う設計です。Google Drive から取得するファイル情報やバックアップデータは、バックアップ、復元、整合性確認、保持方針に沿った削除のためだけに利用します。

保存と共有

  • バックアップ対象のファイルは、restic により Mac 上で暗号化してから、所有者本人の Google Drive に保存する設計です。
  • OAuth トークンなどの認証情報は Mac 上のローカル設定として管理し、この公開ウェブサイトや公開リポジトリには保存しません。
  • このアプリで扱う Google ユーザーデータを、販売、広告配信、AI モデルの学習に利用しません。
  • バックアップの保存先として Google Drive を利用します。このウェブサイトはバックアップファイルや OAuth トークンを受け取るためのものではありません。

保持・削除とアクセスの取り消し

バックアップの保持期間は所有者が設定します。不要なバックアップは、保持方針に基づく削除処理、または所有者による Google Drive 上での削除で管理します。Google Drive のゴミ箱に残る場合があり、完全に削除するにはゴミ箱の処理も必要になることがあります。

所有者は Google アカウントの設定から、このアプリへのアクセス許可を取り消せます。許可を取り消すとバックアップや復元などが利用できなくなる場合がありますが、保存済みのバックアップが自動で削除されるわけではありません。

このウェブサイトについて

このサイトは GitHub Pages で公開しています。サイト自体には独自の入力フォームやアクセス解析を設置しません。ホスティング事業者である GitHub は、サイト配信やセキュリティのために IP アドレスなどのアクセス情報を処理する場合があります。詳しくは GitHub のプライバシー声明 をご確認ください。
